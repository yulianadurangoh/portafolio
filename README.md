# Portafolio web - Yuliana Andrea Durango Hernández

## Descripción

Portafolio web personal construido desde cero con HTML y CSS, como actividad académica.
Incluye una presentación, una sección "Acerca de mí", habilidades, experiencia profesional simulada
y mis actividades organizadas por materia: **Desarrollo** (individuales, grupales y Moodle),
**Algoritmia** e **Inteligencia artificial**.

La página es responsive: se adapta a computador y celular.
